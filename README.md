# 🏃 FitNow · 运动健康信息平台

> 面向体育锻炼与健康管理人士的一站式信息聚合平台 · 手机App原型

## 📌 产品定位

健身爱好者的信息是**割裂**的：赛事在官网、场馆在地图、课程在视频平台、菜谱在小红书。
FitNow 把这些分散资源聚合到一个 App 里，按**时间近、距离近、匹配你**三个维度做推荐。

| 用户痛点 | FitNow 解法 |
|---------|------------|
| 不知道附近有什么运动活动 | 爬取周边 50km 赛事/场馆/课程，按距离排序 |
| 想在家练但不知练什么 | 聚合全网博主跟练课程 + 200+ 标准动作库 |
| 健身却不会吃、不会睡 | AI 生成每日菜谱 + 饮水提醒 + 睡眠计划 |
| 数据散落多个 App | 运动档案、打卡记录、报名记录统一管理 |

## 📱 功能模块

| Tab | 核心功能 |
|-----|---------|
| 🏠 首页 | 今日运动数据统计、热门活动 Banner、今日计划打卡、8 个快捷入口 |
| 📍 附近 | 爬取周边赛事/场馆/课程，地图可视化，分类筛选，一键报名 |
| 🎯 跟练 | 线上课程聚合（HIIT/瑜伽/核心/拉伸）、博主推荐、200+ 动作库 |
| 🥗 健康 | 三餐菜谱时间轴、饮水记录、睡眠建议、营养完成度看板 |
| 👤 我的 | 运动档案、本周柱状图、爬取数据源配置、报名记录管理 |

## 🕸️ 数据爬取

内置 6 个数据源配置项，用户可按需开关：

| 数据源 | 抓取内容 |
|-------|---------|
| 赛事大数据平台 | 马拉松、铁三等官方赛事报名信息 |
| 地图 POI 数据 | 健身房、游泳馆、瑜伽工作室 |
| 活动票务平台 | 大麦/摩登天空线下运动活动 |
| 视频平台博主课程 | B站 / 抖音 / YouTube 跟练内容 |
| 营养健康数据库 | 菜谱、营养素、热量数据 |
| 户外运动平台 | 滑雪场、攀岩馆、户外徒步 |

- 默认每 2 小时自动更新，支持自定义城市与范围
- 接口已预留，可接入 Python Scrapy / Playwright 等真实爬虫

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript，**零外部依赖**
- 单文件交付：App 通过 `iframe srcdoc` 内联注入，样式天然隔离
- 移动端自适应布局，390px 设计基准
- `postMessage` 实现展示页与 App **双向联动**
- CSS 变量统一主题色，便于二次定制
